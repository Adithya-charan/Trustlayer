# B1 compliance matrix

**Notes on the real data:** about a third of the Aadhaar values in the organizer's pack (1,682 of 5,101) are already masked in the source (like `XXXX XXXX 1234`); they are returned as stored and were not counted as secrets. Single first names or misspellings inside free text are not recognised (only full names that exist in the database's name columns are).

Source of truth: the published problem statement ("Smart Data Masking System for PII Protection") and the organizer's dataset README. **Not available to me:** the
hackathon's *Participant Coding Guidelines* / submission instructions (for example a required `FULL_CODE/` folder layout), so no claim is made about them (see row 15).
Results below are from runs on 2026-10-30; commands to reproduce are in `docs/B1.md`.
